# 2026-09-15 高光画面洞察重复问题诊断

## 分流与范围

- lane：`local-dev-light`
- 运行载体：离线报告 renderer / presentation projection / HTML
- 复现输入：`RPA数据汇总/analysis-efficiency-evaluation-20260915/complete-rerun-20260915`
- 受影响章节：`04｜高光画面洞察`

## 用户可见现象

标准分类视图的 `portrait` 与 `product` 分类，以及不同有样本品牌范围中的“共性洞察”和“裂变方向”出现相同正文，页面无法体现不同视觉主体的真实差异。

## 证据

1. 视觉回放分析 JSON 中 `全品牌` 的 `portrait` 与 `product` 两组 `common_patterns` 和 `derivative_directions` 正文逐条相同。
2. `喜纯` 两组同样复用这四段正文。
3. `presentation-report.json` 直接把标准品牌组的正文投影为 Chapter 04 默认内容；`batchClassification` 仅投影分类标签、规则和帧卡片，没有引入重复洞察。
4. 提示词虽要求“不能把同一观点拆句或换词重复”，但现有语义校验只检查结构、字数和帧引用，没有检查同一范围内不同分类组的洞察独立性。

## 根因结论

标准分类组的模型输出允许跨组复制正文，且校验器没有拒绝这种结果；Presentation 层按契约忠实投影，因此重复内容被完整渲染到 HTML。该问题属于标准分类洞察的输入约束和分析质量门禁缺失，不是前端 Tab 切换或图片资产问题。

## 修复方案

1. 在标准分类组校验中，对同一品牌范围内的共性洞察正文和裂变方向正文做归一化去重；重复时拒绝组装。
2. 在提示词中明确要求每个标准分类组围绕该组独有的可见主体、动作、构图或信息机制写作，禁止跨组复制；批次主题继续只输出分类。
3. 重新生成当前真实视觉回放的标准分类洞察，使人物组与产品组分别对应已查看的 5/46 帧，并重新执行 assemble → attest → render → HTML/ZIP 验收。

- Chapter 04 每个有样本标准分类组的洞察正文在同一范围内不重复。
