# 第一部分｜素材榜单数据洞察链路

> 本图是第一部分事实包、提示词和前端报告渲染的固定链路基准。

```mermaid
flowchart TD
    A[pre_input 默认筛选条件]

    A --> B1[当前周期素材列表<br/>所有指定品牌]
    A --> B2[环比周期素材列表<br/>默认条件向前平移等长周期]
    A --> B3[同周期全行业素材列表<br/>不筛选品牌]

    B1 --> C[第一部分事实包]
    B2 --> C
    B3 --> C

    C --> C1[每条素材保留<br/>曝光数据、点击率、转化率、3秒完播]
    C --> C2[排除 RPA 详情数据]
    C --> C3[排除高光帧、秒级数据、视觉分析]

    C --> D1[确定性生成当前表现事实]
    C --> D2[确定性生成环比对比事实]
    C --> D3[确定性生成全行业对比事实]
    C --> D4[确定性筛选爆款素材事实]

    D1 --> E[分析提示词]
    D2 --> E
    D3 --> E
    D4 --> E

    E --> F1[所有指定品牌]
    E --> F2[品牌 A]
    E --> F3[品牌 B]
    E --> F4[其他品牌]

    F1 --> G1[表现与环比/全行业对比分析]
    F1 --> G2[爆款素材整体特征分析]

    F2 --> H1[品牌筛选后的表现与环比/全行业对比分析]
    F2 --> H2[品牌筛选后的爆款素材分析]

    F3 --> I1[品牌筛选后的表现与环比/全行业对比分析]
    F3 --> I2[品牌筛选后的爆款素材分析]

    F4 --> J1[品牌筛选后的表现与环比/全行业对比分析]
    F4 --> J2[品牌筛选后的爆款素材分析]

    G1 --> K[前端报告渲染]
    G2 --> K
    H1 --> K
    H2 --> K
    I1 --> K
    I2 --> K
    J1 --> K
    J2 --> K

    K --> L[Tab：所有指定品牌]
    K --> M[品牌 Tab]

    L --> L1[素材表现洞察]
    L --> L2[环比与全行业对比]
    L --> L3[爆款素材洞察]
    M --> M1[品牌素材表现洞察]
    M --> M2[品牌环比与全行业对比]
    M --> M3[品牌爆款素材洞察]

    L1 --> N1[AI 表现分析段落]
    L2 --> N2[环比/全行业确定性事实面板]
    L3 --> N3[AI 爆款分析段落]
    L3 --> N4[爆款素材事实卡片]

    M1 --> O1[AI 表现分析段落]
    M2 --> O2[环比/全行业确定性事实面板]
    M3 --> O3[AI 爆款分析段落]
    M3 --> O4[爆款素材事实卡片]
```

## 范围约束

- 当前列表与环比列表按 `pre_input` 默认筛选条件生成。
- 全行业列表使用相同时间周期，但不再筛选品牌。
- 品牌范围的环比事实按品牌筛选当前列表与环比列表；全行业对比事实始终引用未筛品牌的全行业列表。
- 曝光、点击率、转化率、3 秒完播的聚合、环比变化和行业差异由事实包确定性计算。
- RPA 详情、高光帧、秒级数据和视觉分析不进入第一部分事实包。
- AI 只解释事实包生成的结果，不重新计算指标；爆款清单由确定性事实面板展示。
