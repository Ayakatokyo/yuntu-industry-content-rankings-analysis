# 云图高光帧与样式化报告设计

## 背景

当前云图技能已经可将 RPA 榜单与素材详情 CSV 规范化，生成面向小仙炖的六章商业分析报告。详情数据包含秒级趋势和云图标记的 `highPoint` / `lossPoint` 区间，但报告尚未下载素材视频、提取画面或在 HTML 中呈现高光帧；现有 HTML 也只是将 Markdown 转义后直接输出，缺少可交付的报告样式。

本设计在当前 `main` 分支的技能内完成高光帧提取与样式化 HTML。不创建通用企业版本，也不改变既有 RPA 采集、数据分析口径、六章结构或 AI 结论契约。

## 目标

- 对每个具备视频 URL 的成功详情素材，固定输出 `0s` 封面帧，并按用户选择的指标提取后续 Top 3 波峰帧。
- 支持“点赞指数”“流失指数”“点击指数”“互动指数”“评论指数”的多选；各指标独立选帧，最后按秒去重。
- 生成可审计的帧清单，向事实包和报告传递成功帧、选帧依据与失败原因。
- 在不改变云图商业分析内容的前提下，将 HTML 报告渲染为深棕、暖金、米白的章节化交付稿，并在“单素材秒级诊断”中展示高光帧画廊。
- 任何视频下载或截图失败均不得阻断事实包、分析 JSON、Markdown 或 HTML 报告的生成。

## 非目标

- 不把云图 `highPoint` 区间等同于“黄金三秒”。黄金三秒仍是固定 `0s` 至 `3s` 的开场范围；本功能只固定截取 `0s`，不额外强制截取 `3s`。
- 不从缺失趋势、`highPoint` 或 `lossPoint` 区间猜测补齐 Top 3 波峰。
- 不保存原始下载视频，不做视频编辑、拼接或视频级输出。
- 不替换或复制参考项目的商业逻辑、报告章节或文案，只参考其视觉语言。

## 命令与输入

批处理命令增加可选参数 `--highlight-trends`，值为一个或多个允许的趋势名称。未传入时维持既有文字报告流程，不触发视频下载或截帧。

传入后仅处理成功规范化详情中的 `video_url`、`trend_series` 和 `high_points`。非法指标名在参数校验阶段失败；重复指标名合并为一次处理。没有 `video_url` 的素材仍写入清单，状态为不可用。

## 选帧规则

### 固定封面帧

每条处理素材都创建 `0s` 候选，原因是 `cover`。仅在视频可下载且 FFmpeg 成功时，它才成为实际 JPEG 帧；失败时保留失败记录。

### 波峰识别

对每个用户选定且有有效逐秒序列的指标独立执行：

1. 先按秒排序并合并同秒数据，只保留该秒的最大值。
2. 将相邻秒的连续非降区间视为一个高位平台，平台只保留值最大的秒；最高值相同时取更早的秒。
3. 保留高于其相邻有效点的候选。曲线首尾若高于唯一相邻点，也可作为峰；单点曲线可作为一个峰。
4. 按趋势值降序、秒数升序排序，选择前三个候选。曲线没有局部波峰时，不从普通点或云图区间补选。

`highPoint` 不是选帧依赖，但会写入候选元数据，标记该秒是否处于同名指标的云图高点区间，供报告说明使用。

### 跨指标去重

所有指标的前三峰与 `0s` 按秒数合并。同一秒只截取一张图片，累积其命中的指标名称、趋势值、该指标内峰值名次，以及 `highPoint` 命中状态。清单和报告按秒数升序展示，封面帧始终列在最前。

## 提取、产物与降级

新增独立的高光帧库，负责参数校验、视频下载、FFmpeg 调用、帧写入和清单组装；批处理编排层只调用该库并向下游传递结果。

- 下载视频到受控临时目录，设置超时与最大响应大小，完成或失败后删除临时文件。
- 使用 FFmpeg 在各目标秒提取 JPEG。输出落在 `highlights/<material_id>/`，文件名含固定顺序和秒数。
- 根目录写入 `highlights-manifest.json`。每条素材列出视频来源、请求帧、每帧路径、选帧依据、可用状态和失败原因。
- 下载失败、FFmpeg 缺失、非零退出、无视频 URL 或单帧失败时，将失败原因写入对应素材或帧；继续处理其他素材、事实包与报告。
- 不以远程 URL 作为 HTML 图片来源；HTML 只使用已经产出的本地相对 JPEG 路径，避免报告浏览时再次发起网络请求。

## 事实包与报告

事实包的详情素材新增 `highlight_frames` 和高光帧可用性摘要。可用帧包含：相对路径、秒数、是否封面、命中指标、对应趋势值、指标内名次及云图高点区间标识；失败帧只包含状态和原因，不伪造路径。

Markdown 保持现有六章和文本契约。HTML 改由语义化章节渲染，而不是转义 Markdown：

- 深色报告封面，展示报告名称和生成信息。
- 米白正文与暖金章节编号，使用现有六章的标题和排序。
- 证据内容、素材对比与实验矩阵保留结构化信息；实验矩阵在小屏幕可横向滚动而不挤压字段。
- “单素材秒级诊断”按素材渲染高光帧画廊。`0s` 帧标识为“封面”，其他帧按秒标识并显示命中指标和值；没有可用帧时只显示原有文字诊断。
- 样式仅参考 `/Users/shuzida/Desktop/FDE客户/小仙炖/qianchuan-video-peak-frames/templates/final-report-template.html` 的深棕、暖金、米白与章节卡片语言，不迁移其业务内容。

## 错误处理

- `--highlight-trends` 未传入：高光帧功能完全跳过，既有流程行为不变。
- 详情趋势为空、指标不存在、峰不足三处：保留实际可选峰数，不补齐；`0s` 仍尝试提取。
- 视频 URL 空、下载失败、文件过大、FFmpeg 不可用、视频不可读或单帧失败：清单写明原因，批处理以成功状态进入后续报告生成。
- 高光帧目录或图片相对路径无效：HTML 不输出损坏的 `<img>`，改为文字诊断。
- 分析 JSON 本身不满足既有六章或证据契约时，维持当前报告拒绝生成行为；高光帧功能不得绕过该校验。

## 验证与验收

- 单元测试覆盖参数校验、`0s` 固定候选、局部波峰、连续高位平台合并、首尾峰、每指标 Top 3、跨指标按秒去重和 `highPoint` 仅作标记。
- 以受控模拟视频测试 FFmpeg 截帧、JPEG 写入、清单字段和单帧失败降级。
- 集成测试验证高光帧元数据进入事实包，HTML 有画廊且无帧时回退文字诊断；未传参数的旧流程保持兼容。
- 使用已有真实 RPA 归一化数据运行离线回归。视频仍可访问时验证真实帧；不可访问时确认清单降级且报告仍完整产出。
- 使用浏览器在桌面和移动宽度截图验证 HTML：封面、六章、表格与高光帧画廊均可见，图片和标签不重叠、不溢出。
