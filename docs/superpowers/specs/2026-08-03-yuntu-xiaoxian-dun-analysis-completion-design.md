# 小仙炖云图行业内容榜单分析闭环设计

## 背景

当前技能可以通过固定 RPA 连接器获得榜单 CSV 和素材详情 CSV，但真实 RPA CSV 的嵌套字段使用 Python 字面量格式（单引号），而现有解析器只识别标准 JSON。结果是 `object_index`、标签数组和 `trends` 被保留为字符串，规范化阶段无法读取它们，最终事实包缺少指标、标签和秒级趋势，报告无法形成可靠的商业结论。

本设计只完善当前的“小仙炖云图行业内容榜单分析”技能，不创建通用技能或报告分支。

## 目标

- 将真实 RPA CSV 中的榜单指标、标签和素材秒级趋势稳定转换为规范化 JSON。
- 将规范化素材数据汇总为可审计的分析事实包，提供比较、分层和机会判断所需的计算结果。
- 生成面向小仙炖的闭环商业分析报告，所有结论均可追溯到素材 ID、标签、指标或秒级趋势。
- 对缺失、非法或无法安全解析的数据明确降级，不能把无依据的推断写为事实。

## 非目标

- 不新增另一套通用企业分析技能。
- 不改变固定 RPA 连接器、账号授权、网关和批处理语义。
- 不下载视频、提取画面或调用外部模型；模型仍只基于事实包生成结构化结论。
- 最终报告不设置“数据范围与可信度”或“风险与待补数据”章节。

## 数据处理设计

### CSV 单元格解析

保留现有标准 JSON 支持，并为以 `{` 或 `[` 开头的单元格增加安全的 Python 字面量解析。仅接受 `dict`、`list`、字符串、数值、布尔值和空值；不可解析值保留原字符串，由调用方按字段类型决定是否使用。不得执行任意代码。

解析后继续使用 CSV 标题作为字段名。榜单记录应提供：素材 ID、标题、榜单顺序、时长、发布时间、指标、按原始类别保留的人群标签和内容标签。详情记录应提供：素材 ID、日期范围、视频 URL、每条趋势的逐秒序列、高点和流失区间。

### 规范化与数据质量

榜单的数值字段转换为数值；无法转换的字段不写入相应指标。标签只接受列表条目中的非空文本。详情趋势只接受包含有效秒数和数值的点；高点和流失点必须保留原趋势名称与秒数边界。

规范化输出新增数据可用性摘要，按素材记录指标、标签和趋势是否可用及其缺失原因。原始 CSV 始终保留，后续分析只读取 `normalized/` 中的产物。

## 分析事实包设计

事实包以成功获取详情的 `selectedMaterials` 为单素材诊断范围，以完整 `list-records.json` 为行业候选池比较范围。它包含：

- 素材级事实：排名、标题、时长、发布时间、指标、人群标签、内容标签和秒级趋势摘要。
- 榜单比较：每个可用指标的候选池均值、中位数、分位位置及素材分层。候选池不少于 4 条时，以指标前 25% 定义“高表现”；少于 4 条时仅展示排名与原始指标。曝光量按曝光数加权汇总，其他比率指标不伪造加权结论。
- 内容与人群：标签出现次数、覆盖素材数、与高表现素材的交集。只有候选池不少于 4 条且标签至少覆盖 2 条素材时，才输出标签与高表现素材的共现；不将共现表述为因果。
- 秒级诊断：按“点击指数”“互动指数”“点赞指数”“评论指数”和“流失指数”分别汇总高点、流失区间、首 3 秒和首 5 秒表现；缺少趋势时只显示不可用，不生成诊断。
- 小仙炖机会：将竞争素材中的卖点、场景、促销表达、人物与叙事方式拆为可复用创意信号，并标明来源素材和相关指标。

所有计算都输出原始数值和可读展示值，百分比只在源字段为比率时格式化，不修改底层精度。

## 小仙炖分析规则

模型输入提示要求按事实包作答，且把“事实”“解释”“测试假设”分开表达：

- 事实必须引用素材 ID，并写出排名、指标、标签或秒级区间中的至少一项证据。
- 解释只能说明观察到的表现与内容要素之间的可能关系，不得声称因果。
- 测试假设必须说明小仙炖可测试的创意变量、目标人群、观察指标和判定标准。
- 涉及滋补、孕期、功效或人群健康的内容，只能提出需由业务与合规确认的表达方向，不生成未经验证的功效宣称。

当必要数据为空时，固定使用“数据不足以判断”，并转为下一轮测试建议，而不是补造结论。

## 报告模板

报告固定为以下六章：

1. **榜单机会总览**：行业候选池的排名、规模和可观察到的核心机会，点明高表现内容的共同信号。
2. **素材表现对比**：入选素材的指标、分位和内容元素横向对比，明确每项比较的口径。
3. **单素材秒级诊断**：逐素材列出开场承接、指标高点、流失区间、可借鉴做法和应避免的问题。
4. **竞品创意模式**：归纳有证据支持的卖点、场景、人物、促销和叙事模式，附来源素材。
5. **小仙炖机会地图**：按人群、需求场景、内容钩子和产品表达组织可测试机会，区分直接可借鉴与需品牌化改写的方向。
6. **下一轮实验矩阵**：按优先级列出假设、素材变量、目标人群、成功指标、对照方式和复盘动作。

结构化 AI 输出与 Markdown/HTML 渲染器使用同一章节契约。渲染器负责展示，不创建业务判断。

## 错误处理

- CSV 文件为空、表头无效、行字段数异常时，维持现有失败行为并停止相关阶段。
- 单元格嵌套结构无法解析时，不中断整批任务；该字段降级为不可用并体现在数据可用性摘要中。
- 素材 ID 不匹配、详情记录结构不合法或没有任何成功详情时，保持现有批次失败语义。
- 报告输入缺少必需章节、任一素材级结论的素材 ID 证据，或实验矩阵的假设、变量、目标人群、成功指标、对照方式和复盘动作时，渲染阶段拒绝生成最终报告。

## 验证与验收

- 用用户提供的真实榜单 CSV 和详情 CSV 回归，验证至少一个榜单记录提取到 CTR、曝光、标签和发布时间，至少一个详情记录提取到趋势、高点和流失点。
- 覆盖标准 JSON、Python 字面量和不可解析嵌套单元格三种 CSV 情形。
- 覆盖事实包的候选池比较、素材分层、标签交集、秒级摘要和无数据降级。
- 覆盖小仙炖 AI 输出的章节契约、证据引用要求及实验矩阵字段校验。
- 报告渲染包含六个确认章节，且没有被移除的“数据范围与可信度”或“风险与待补数据”章节。
