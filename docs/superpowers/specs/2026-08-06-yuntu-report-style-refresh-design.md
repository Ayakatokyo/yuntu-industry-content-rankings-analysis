# 云图报告样式优化设计

**日期：** 2026-08-06  
**范围：** 仅优化 HTML 报告的视觉样式与现有交互；不改变六章顺序、洞察 JSON 契约、事实包字段或分析口径。

## 背景

真实执行已产出 1,000 条榜单候选、10 条秒级详情和 100 张高光帧。复盘显示报告数据完整、可自包含，但用户可见层仍有三个问题：视觉层级偏平、证据文本以 JSON 形式直出、素材帧在移动端和单独交付时缺少更成熟的浏览体验。

主读者是小仙炖抖音内容团队。当前阶段优先提高阅读、定位和素材复盘效率；整体报告结构重构留待后续单独推进。

## 设计目标

1. 保留深棕、暖金、米白的现有品牌气质，并与 `qianchuan-video-peak-frames/templates/final-report-template.html` 的层次语言对齐。
2. 不改变现有章节、原有洞察文本及指标含义。
3. 让结论、证据、指标、高光帧具有清晰且稳定的视觉优先级。
4. 保持 HTML 离线可用，图片仅使用已生成的本地路径或内嵌 data URI，不请求远程资源。
5. 在 390px 和 1440px 宽度下避免文字、图像、标签和控件溢出或重叠。

## 非目标

- 不重排六章顺序，也不新增业务章节或图表数据。
- 不修改 `yuntu-ai-analysis.json` 所需字段、校验规则或业务结论。
- 不改变高光帧抽取、压缩、内嵌或失败降级逻辑。
- 不将报告改造成需要网络服务的 SPA。

## 视觉系统

沿用现有色相，统一为可复用变量：深棕背景 `#120b08`、米白页面 `#fff8ec`、正文深色 `#2a170f`、辅助文本 `#806758`、暖金强调 `#d79a4b`。正文区使用半透明米白面板、细描边和柔和阴影；圆角基于模板统一为 16px 至 28px，避免同一报告内混用过多半径。

封面使用深色半透明卡片承载标题、时间口径、品牌范围和摘要。章节容器统一使用米白面板；章序号、P0-P2、素材 rank 和可点击素材引用使用暖金，但不依赖颜色传递唯一信息。

字体使用系统中文字体栈。标题使用固定层级和紧凑行高，正文维持 15px 至 18px 的可读范围；不使用 viewport 相关字号。

## 页面元素

### 现有六章

保留现有报告封面、概览 dashboard、六章洞察和单素材诊断的出现顺序。每章的洞察卡分为：

- 结论主体：优先显示 `summary` 或实验假设。
- 元信息：优先级或素材引用以标签展示。
- 证据：保留原始证据内容，但默认折叠在原生 `details` 中，摘要标记为“查看数据依据”。

这减少长证据对浏览节奏的干扰，同时保持内容团队核查依据的能力。没有证据或数据不足时，保持现有文本，不制造可展开的空区域。

### 指标与标签

dashboard、素材指标和标签使用同一描边、背景和数值字重体系。指标网格在桌面保持四列，在窄屏收为两列；标签允许自动换行且不撑开卡片。`P0`、`P1`、`P2` 使用文字加颜色，而不是仅以色块区分。

### 高光帧

可用高光帧呈现为稳定的固定比例缩略图，显示“封面”或秒数标签。点击后进入已有 lightbox，支持关闭按钮、遮罩点击和 Escape；补充焦点样式与 `aria` 标签。无可用帧时保留降级提示，不渲染损坏图片或空白网格。

### 导航与移动端

素材锚点导航保持横向滚动且不遮挡正文。所有交互控件满足键盘焦点可见；窄屏下封面、章节和素材卡减少内边距，长标题换行，缩略图网格至少保留三列且不拉伸图片比例。

## 实现边界

`scripts/yuntu_report.py` 只调整 HTML 标记、内嵌 CSS 与已有 lightbox 相关脚本。Markdown 渲染、输入校验、`final-report-data.json`、图片路径判断与事实包消费逻辑保持不变。

测试新增或调整为验证：封面和章节样式类存在、证据使用可访问的折叠容器、可用帧保留 lightbox 交互属性、失败帧不输出图片、现有六章和 HTML 转义保证不回退。基于真实产物重渲染后，进行桌面与移动浏览器截图检查，并扫描 HTML 确认无远程请求和无内部路径泄露。

## 错误处理

分析 JSON 不满足既有校验时继续拒绝渲染。高光帧缺失或不可用时继续显示素材诊断，不阻断报告。JavaScript 不可用时，章节、证据文本和缩略图仍可阅读；仅大图预览不可用。

## 验收标准

1. 现有真实数据能直接重渲染，且六章、素材数、洞察文本和数据口径不变。
2. HTML 使用统一的暖色视觉变量、封面、章节面板、洞察层级和高光帧状态。
3. 证据内容不再以裸露 JSON 作为主体阅读内容，仍可按需展开核查。
4. 桌面与移动视口中不存在重叠、横向正文溢出或失焦交互控件。
5. 单文件报告不依赖远程资源；高光帧继续遵守内嵌或本地相对路径的既有交付策略。
