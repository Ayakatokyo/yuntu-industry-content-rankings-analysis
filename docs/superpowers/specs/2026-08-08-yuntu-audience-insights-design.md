> 范围：云图行业内容榜单分析报告第二部分

## 1. 目标

在报告中恢复独立的 `02｜人群洞察` 章节，以当前运行提取到的候选素材池中、按曝光稳定排序的前 1000 条素材为样本，展示：

1. 年龄标签的素材占比。
2. 性别标签的素材占比。
3. 八大人群标签的素材占比或覆盖率。
4. 各维度的数据口径、有效样本数和未标注数量。

这部分是确定性的数据看板，不调用 AI 生成结论，不把审计 evidence 写入用户可读正文。

## 2. 范围与边界

### 2.1 分析集合

分析集合独立于第一部分的 TOP30：

- 输入为 RPA 后已规范化的列表素材。
- 仅纳入 `show_cnt > 0` 的素材。
- 按 `show_cnt` 降序、原始排名升序、素材 ID 升序的稳定顺序，最多取 1000 条。
- 候选池不足 1000 条时使用实际可用数量，并在报告中显示实际数量；不补造数据。
- 聚合前保留第一部分既有的标题匹配品牌分类，但本期看板的首个视图是全部候选池，不把不同来源静默混合成品牌结论。

`02` 的素材覆盖率分母是入选的素材条数，而不是曝光量、用户数或人群包人数。饼图分母则是该维度所有有效标签的出现次数。图表不得称为“受众占比”。

### 2.2 不在本次范围内

- 不修改 `scripts/rpa_connector.py`、`scripts/yuntu_batch.py`、`references/connectors/**` 或任何 RPA 能力。
- 不改写 `01｜TOP 素材组合结论` 的 TOP30、人群曝光加权覆盖或品牌 Tab。
- 不推断年龄、性别或八大人群的真实用户规模。
- 不以数据不足为由生成模拟百分比。

## 3. 聚合口径

原始 `people_tags` 是一条素材的标签集合。每个维度只识别既有枚举：

| 维度 | 有效标签 |
|---|---|
| 年龄 | `18-19`、`20-23`、`24-30`、`31-35`、`36-40`、`41-45`、`46-50`、`51-55`、`56-59`、`60+` |
| 性别 | `女`、`男` |
| 八大人群 | `小镇青年`、`精致妈妈`、`新锐白领`、`资深中产`、`小镇中老年`、`都市银发`、`genz`、`都市蓝领` |

对每个维度和每个标签，计算：

```text
materialCount(label) = 含该标签的入选素材数
materialShare(label) = materialCount(label) / 入选素材总数
tagOccurrenceCount = 所有有效标签在入选素材中的出现次数之和
chartShare(label) = materialCount(label) / tagOccurrenceCount
```

输出还应包含：

- `recordCount`：本次入选素材总数。
- `labeledRecordCount`：该维度至少命中一个有效标签的素材数。
- `unlabeledRecordCount`：该维度未命中有效标签的素材数。
- `tagOccurrenceCount`：该维度有效标签的总出现次数。
- `chartShare`：用于图表的归一化标签出现次数占比。
- `labelMode`：固定为 `normalized_tag_share`。

### 3.1 图表口径

年龄和性别使用饼图，八大人群使用竖向柱状图。原始标签可以重叠，不能把 `materialShare` 直接表达为互斥构成比；否则各标签之和可能超过 100%。

因此所有维度固定采用 `normalized_tag_share`：按标签出现次数归一化，`chartShare` 总和为 100%。未识别标签不计入图表分母，也不补为“未标注”分片。每个图例、柱状图 tooltip 和 hover 提示同时显示素材数、真实素材覆盖率与归一化占比，并固定说明：`图表按素材标签出现次数归一化展示，用于观察标签结构，不代表真实人群分布。`

## 4. 报告呈现

### 4.1 章节结构

在现有 `01` 之后新增：

```text
02｜人群洞察
候选池 TOP1000 素材标签汇总（实际 N 条）
年龄
性别
八大人群
```

侧边目录增加 `02｜人群洞察`。移动端沿用当前的横向可滚动目录。Markdown 使用相同标题、数据口径和列表表述，不尝试模拟交互图形。

### 4.2 图表组件

- 报告容器：最大宽度 1180px；目录列保持固定，正文列随剩余宽度扩展，避免双列卡片被固定正文宽度挤压。
- 桌面端：年龄和性别为双列卡片；每张卡片采用左侧 45% 饼图、右侧 55% 指标列表；八大人群卡片独占一行。
- 同行卡片对齐：年龄和性别卡片拉伸为一致高度，饼图与指标列表共同在剩余高度内垂直居中，避免少标签的性别饼图向上漂移。
- 移动端或卡片容器不足 360px：卡片单列，饼图居中，指标列表置于下方；桌面双列卡片保持左图右指标。
- 年龄饼图：最大宽度 260px；右侧指标列表完整展示年龄段、素材数和归一化占比。
- 性别饼图：最大宽度 240px；右侧指标列表完整展示女、男的素材数和归一化占比。
- 指标列表：三列网格为“含色块的标签｜素材数｜归一化占比”；标签不省略，数字右对齐。
- 八大人群柱状图：复用参考报告的纵向柱、网格线、底部完整标签和 hover tooltip；柱高表示归一化占比，颜色采用棕金色系。
- 无有效数据：保留卡片和“暂无可视化数据”，同时显示该维度的未标注数量。
- 无 JavaScript：由服务端渲染静态图例、比例和口径；用户不依赖 hover 才能获得信息。

### 4.3 文案约束

- 固定口径：`图表按素材标签出现次数归一化展示，用于观察标签结构，不代表真实人群分布。`。
- 图例与 hover：`素材数 X 条，覆盖率 Y%，归一化占比 Z%`。
- 未标注：`未识别到该维度标签`，不得称为“其他人群”。
- 不输出 `evidence`、`查看数据依据`、审计 JSON 或模型思考文本。

## 5. 数据合同与模块职责

新增纯后处理事实，不接触 RPA：

```json
{
  "schemaVersion": 1,
  "sample": {
    "scope": "candidate_pool_top_1000",
    "requestedLimit": 1000,
    "recordCount": 764
  },
  "dimensions": {
    "age": {
      "labelMode": "normalized_tag_share",
      "recordCount": 764,
      "labeledRecordCount": 730,
      "unlabeledRecordCount": 34,
      "tagOccurrenceCount": 760,
      "buckets": [
        {"label": "24-30", "materialCount": 311, "materialShare": 0.4071, "chartShare": 0.4092}
      ]
    }
  }
}
```

实现位置：

- `scripts/yuntu_top_materials.py`：从同一份规范化记录生成候选池 TOP1000 的人群事实，复用既有年龄、性别、八大人群枚举与稳定排序。
- `scripts/yuntu_analysis.py`：把结构化人群事实写入分析包。它不需要 AI 回填用户正文。
- `scripts/yuntu_report.py`：校验人群事实、生成 Markdown 的静态摘要，并将图表数据安全注入 HTML。
- `scripts/templates/final-report-template.html`：独立渲染 `02`，不嵌入或重构 `01`。

## 6. 测试与验收

1. 1000 条以上的输入稳定截取前 1000；少于 1000 条保留实际条数。
2. 年龄、性别、八大人群都正确统计素材数和素材占比。
3. 年龄、性别、八大人群均生成 `normalized_tag_share`，每个有数据维度的 `chartShare` 总和为 100%。
4. 年龄、性别输出缩小饼图和完整图例；八大人群输出竖向柱状图，包含底部标签和 hover tooltip。
5. 图表和正文均明确标签可重叠，且同时保留真实素材覆盖率与归一化占比。
6. 无标签、无曝光及无效记录不导致除零或虚构比例。
7. HTML 含 `02`、导航项、图表图例、可访问文本和正确的模式文案；Markdown 含等价静态信息。
8. `01` 的既有内容、品牌 Tab、无证据正文约束和 7 个顶层分析键保持通过。
9. 运行完整单测、`python scripts/rpa_connector.py self-test` 与 `git diff --check`；不使用浏览器工具。
