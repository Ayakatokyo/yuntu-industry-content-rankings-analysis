# 01｜TOP 素材组合结论设计

> 状态：已确认，待实施
>
> 范围：云图行业内容榜单分析 2.0 的第一报告板块。仅覆盖 RPA 执行完成后的数据提取、业务分析和报告呈现；不修改 RPA 连接器、批次抓取、续跑或 CSV 落盘能力。

## 1. 目标与边界

本板块不是素材推荐榜，也不逐条评价素材好坏。它基于当前筛选条件下 RPA 已落盘的 TOP1000 素材，回答两个业务问题：

1. 当前筛选品牌集合的曝光 TOP30，整体呈现什么样的数据、人群和营销卖点结构？
2. 按可审计标题规则识别后的每个品牌，其自身曝光 TOP30 与其他品牌有何差异？

本板块只输出“TOP 素材组合结论”，以结论和证据为主体，不拆分高点击、高转化、高留存等并列专题，不依赖秒级详情、高光帧或 AI 对画面的猜测。

### 非目标

- 不修改 `scripts/rpa_connector.py`、`scripts/yuntu_batch.py`、RPA 固定连接器元数据、重试和 CSV 主路径。
- 不以标题或标签推测触点；触点字段缺失时，正式 2.0 的触点分组报告继续阻断。
- 不把标题匹配得到的品牌归属表述成 RPA 原生品牌字段。
- 不把重叠人群标签的曝光覆盖率表述为互斥人群占比或真实人群曝光比例。
- 不从曝光推算 CPM、消耗、点击数或转化数。
- 本次不纳入环比上周。环比需要可比上周期运行数据和独立的周期设计后再加入。

## 2. 当前真实数据验证

验证样本：`RPA数据汇总/yuntu-rankings-analysis`。

| 项目 | 当前结果 | 设计影响 |
|---|---:|---|
| 榜单范围 | 2026-07-26 至 2026-08-01，曝光量 TOP1000 | 可验证全量候选池与 TOP30 逻辑 |
| 素材记录 | 1,000 条 | 数据和标签汇总以全量或各自 TOP30 为基数 |
| 可用核心指标 | 曝光、CTR、CVR、PVR、3S、5S、完播、互动率、组件点击率、平均播放时长 | 十项均可计算素材级均值、中位数和曝光汇总 |
| CPM | 未提供 | 本板块显示“RPA 未提供”，不估算 |
| 素材级品牌字段 | 未提供 | 品牌分析使用标题规则，保留规则来源 |
| 人群比例字段 | 未提供 | 只能计算标签关联素材的曝光覆盖率，不能计算真实受众占比 |
| 素材级触点字段 | 未提供 | 不能生成正式触点分组结论 |

当前标题规则在 1,000 条样本中的覆盖情况：五个女博士 292 条、万益蓝/WONDERLAB 368 条、燕之屋 182 条、未知品牌 158 条。规则命中后的头部素材也与肉眼可核验标题一致，例如五个女博士的榜单第 1 至 3 位、万益蓝的第 7 至 8 位、燕之屋的第 23 至 24 位。

## 3. 数据输入与共同规则

### 3.1 输入

业务层只读取已有的规范化列表记录、批次清单和后续 v3 事实包：

- `batch-manifest.json`：筛选条件、周期、候选数量及来源状态。
- `normalized/list-records.json`：标题、原始 rank、曝光、十项指标、人群标签、营销标签、发布时间、素材时长及来源路径。

`raw-csv/` 只用于审计追溯，不作为报告计算输入。详情、高光和视频 URL 不属于本板块的必填输入。

### 3.2 TOP30 选择

对任意素材集合按以下键排序并取前 30 条：

```text
show_cnt DESC, rank ASC, material_id ASC
```

`show_cnt` 缺失或非正数的素材不进入曝光 TOP30，并在数据可用性统计中记录。集合少于 30 条时展示实际数量，不补位或跨品牌合并。

### 3.3 指标汇总

对于 CTR、CVR、PVR、3S 完播率、5S 完播率、完播率、互动率、组件点击率和平均播放时长：

- 输出素材级算术均值、中位数和有效样本数。
- 不将单素材比例相加，也不以曝光隐式推导点击、转化或播放量。
- `component_click_rate` 与 CTR 数值相同或语义重复时，报告保留数据可用性说明，不输出重复结论。

对于曝光：

- 输出总曝光、平均曝光、中位曝光、最大素材曝光和前 3 素材曝光占 TOP30 总曝光的比例。
- 输出 TOP30 总曝光占所在全量素材池总曝光的比例。
- 当“前 3 素材曝光占比”达到业务配置阈值时，才可作“曝光集中”结论；未配置阈值只报告事实值。

CPM 仅在输入字段存在、数值合法且语义明确为每千次曝光成本时显示；缺失时固定为“RPA 未提供”。

## 4. 标题品牌识别

品牌归属是业务规则派生字段，命名为 `brandClassification`，不得覆盖或伪装为未来 RPA 返回的 `brand` 字段。

| 归属 | 标题匹配规则 | 结果标签 |
|---|---|---|
| 万益蓝/WONDERLAB | 标题包含“万益蓝”或忽略大小写后包含“wonderlab” | `title_rule` |
| 五个女博士 | 标题包含“五个女博士” | `title_rule` |
| 燕之屋 | 标题包含“燕之屋” | `title_rule` |
| 未知品牌 | 未命中上述任一规则 | `unclassified` |

同一标题若命中多个品牌规则，归入 `ambiguous`，不进入任何单品牌 TOP30，并写入数据质量告警。未知与歧义素材保留在“品牌筛选条件下 TOP30”整体分析中，但不进入品牌间比较。

品牌规则配置必须独立于 RPA 脚本，由业务分析层读取；每个品牌结论都显示“标题匹配归属”标识和识别素材数，防止将覆盖率误读为全量真实品牌规模。

## 5. 报告呈现

报告一级区块固定为：

```text
01｜TOP 素材组合结论
```

区块以结论为先。每个结论由一句业务判断、紧随其后的关键数字、样本数、品牌归属方式和素材证据构成；不创建独立的素材推荐榜或逐条诊断页。

### 5.1 品牌筛选条件下 TOP30 素材整体分析

分析对象为当前筛选品牌集合下的全部素材，按曝光选择 TOP30。输出三类结论：

1. **数据结论**：TOP30 总曝光及其在 TOP1000 的曝光占比；十项素材级指标的均值、中位数与有效样本数；前 3 素材曝光集中度；TOP30 与 TOP1000 全量池在曝光、点击、转化和播放完成上的差异。
2. **人群结论**：年龄、性别、八大人群标签的素材数量占比和曝光加权覆盖率；标注“标签可重叠，覆盖率不可相加为 100%”。
3. **营销卖点结论**：成分/原料、功效、痛点、使用场景、内容形式及促销利益的高频标签、关联素材数和关联曝光覆盖率；素材数量少但关联曝光高的卖点需要单独指出。

标签与指标的关系只在每侧有效素材数均不少于 3 时输出“共现差异”：比较带标签素材与不带标签素材的 CTR、CVR、3S 完播中位数，连同两侧样本数显示。它只说明数据共现，不说明卖点导致指标提升。

### 5.2 各品牌下 TOP30 素材分析

对标题规则识别成功的每个品牌，分别从该品牌全部可识别素材中按曝光选择 TOP30，使用与整体分析完全相同的数据、人群和营销卖点口径。每个品牌至少输出：

- 可识别素材总数及其在本次筛选全量中的覆盖率。
- 品牌 TOP30 总曝光、该 TOP30 占本品牌可识别素材曝光比例、平均曝光和中位曝光。
- 十项指标的均值、中位数与有效样本数。
- 年龄、性别、八大人群的素材数量占比和曝光加权标签覆盖率。
- 高频卖点及关联曝光覆盖率；成分、功效、场景、痛点、内容形式、促销利益的主要表达重心。

区块结尾给出品牌差异总结：以可识别素材覆盖、TOP30 曝光集中度、指标中位数、人群标签覆盖与卖点结构为证据，描述品牌间差异和同质化。任何“最强”“短板”等判断必须指定比较指标、样本数和阈值；样本不足时写“数据不足以判断”。

## 6. 人群与营销标签分类

### 6.1 人群

`people_tags` 中的值按固定规则分类：

- 年龄：18-19、20-23、24-30、31-35、36-40、41-45、46-50、51-55、56-59、60+。
- 性别：女、男。
- 八大人群：小镇青年、精致妈妈、新锐白领、资深中产、小镇中老年、都市银发、GENZ、都市蓝领；大小写及平台别名在业务层统一。

当前样本中年龄、性别与八大人群均以标签形式存在，但没有单人群比例。因此：

```text
素材数量占比 = 带标签的 TOP30 素材数 / TOP30 素材数
曝光加权标签覆盖率 = 带标签的 TOP30 素材曝光之和 / TOP30 总曝光
```

同一素材可能同时带多个年龄、性别或人群标签，故两个指标均是覆盖率，不代表互斥人群结构。

### 6.2 营销卖点

`material_tags` 按可解释的前缀和受控映射聚合为：成分/原料、功效、痛点、使用场景、内容形式、促销利益。没有稳定前缀或不在映射表中的标签保留为“其他”，不得静默丢弃。原始标签、聚合类别、素材数量、曝光覆盖率和来源素材 ID 都要进入事实包。

## 7. 数据质量与失败策略

| 情况 | 报告行为 |
|---|---|
| CPM 不存在 | 显示“RPA 未提供”，不估算 |
| 任何核心指标部分缺失 | 保留有效样本数与缺失数；不将缺失当作 0 |
| 标题未命中品牌 | 归为未知品牌，仅参加整体 TOP30 |
| 标题命中多个品牌 | 归为歧义品牌，排除品牌 TOP30 并发出告警 |
| 品牌识别素材少于 1 条 | 不生成该品牌 TOP30，显示“无可识别素材” |
| 品牌素材少于 30 条 | 以实际数量计算并标注覆盖范围 |
| 标签两侧样本任一少于 3 条 | 不输出指标共现差异 |
| 没有触点字段 | 不显示或推测触点级结论 |

## 8. 验收条件

- [ ] 所有整体和品牌 TOP30 都按曝光、原 rank、素材 ID 的确定性顺序选择。
- [ ] 整体 TOP30 包含未知及歧义品牌；各品牌 TOP30 只包含单一标题规则命中的素材。
- [ ] 每条品牌级结论都显示标题规则归属、识别素材数和素材证据。
- [ ] 十项当前可用指标均输出均值、中位数和有效样本数；CPM 缺失时不出现数值或推导值。
- [ ] TOP30 总曝光、TOP1000 占比、前 3 曝光集中度的分子和分母可由事实包复算。
- [ ] 年龄、性别、八大人群同时输出素材数量占比与曝光加权标签覆盖率，并明确它们可重叠。
- [ ] 所有营销卖点结论可追溯到原始标签和素材 ID；“共现差异”始终附带样本数，且不宣称因果。
- [ ] 对品牌未知、歧义、指标缺失和不足 TOP30 的情况有可读的降级说明。
- [ ] 实现过程不修改 RPA 连接器、批次抓取、CSV 主路径和中断恢复能力。
