# 云图单素材深度分析帧优先设计

## 目标

重构报告的 `05｜单素材深度分析`，严格对齐千川报告的阅读骨架，同时适应云图视频 URL 会过期的事实。页面不尝试播放或嵌入视频，六张高光帧成为原有“视频 + 右侧帧序列”视觉区的唯一媒体内容。

## 已确认的体验

- 桌面端使用左侧竖向素材页签和右侧单素材面板；默认展示榜单排名最高的入选素材。
- 每个面板顶部的视觉区固定为六格 `3 x 2` 帧序列。帧按秒数升序排列，使用完整画面比例 `object-fit: contain`，点击可打开大图。
- 不渲染视频 URL、`video` 标签、播放器、海报或链接失效提示；没有成功帧时展示帧可用性和失败原因。
- 高光帧观察独立于图片条呈现，保留逐帧观察和素材级画面总结。
- `秒级拆解` 复用千川的单张交互曲线架构：五个云图指数作为切换项、坐标轴、点位提示、峰值文字、范围滑杆。高点和流失区间作为云图特有覆盖层保留。
- 不引入脚本、话术、真实次数、转化归因或因果结论；不增加移动端专门布局。

## 数据与失败处理

仅消费现有 `materialDeepDives`、`highlightFrames` 和 `secondLevelBreakdown`。成功帧仍要求只被引用一次；指标顺序固定为点赞、流失、点击、互动、评论。失败帧不生成伪图片路径，而是在素材面板显示成功数、总数和事实包给出的失败原因。

## 验收

- HTML 具有千川式侧边页签、右侧面板、固定六格帧区及独立观察区。
- 输出不含 `video` 标签或云图视频 URL。
- 秒级拆解存在单指标切换、坐标语义、点位提示、峰值注记和范围控制；五指标可切换。
- 帧不可用时有覆盖说明与失败原因。
- 现有事实/分析校验不变，完整单测通过。
