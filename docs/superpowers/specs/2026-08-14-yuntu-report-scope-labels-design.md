# 云图报告章节范围标签优化设计

**日期：** 2026-08-14  
**状态：** 已确认，待实现

## 目标

让读者在各章节直接识别结论的数据范围，同时删除 05 章面向读者的内部高光帧覆盖率文案。

## 范围标签

- `01｜TOP 素材组合结论`：同时显示 `TOP1000 榜单素材` 与 `成功秒级拆解素材`。
- `02｜人群洞察`：显示 `TOP1000 榜单素材`。
- `03｜脚本洞察`：不显示范围标签，保留“脚本数据：未接入”的真实状态。
- `04｜高光画面洞察`：显示 `成功秒级拆解素材`。
- `05｜单素材深度分析`：显示 `成功秒级拆解素材`。

标签复用事实包中的 `reportScopes` 数据，只显示来源名称与实际样本数。不得创建第三套读者可见数据口径。

## 05 章调整

删除“高光帧可用：x/y”及其失败原因的读者可见文案。没有可用帧时，仍保留既有的明确不可用状态和失败原因。

## 非目标

- 不将 `reportScopes` 写入 `final-report-data.json`；该文件仅供技能内部分析和报告注入使用。
- 不改变 04 章保留每条素材零秒封面帧的既定规则。
- 不接入脚本正文或脚本时间轴数据。

## 验收

1. 五章标签分别符合上述映射，03 章不显示范围标签。
2. 01、02、04、05 使用事实包实际样本数。
3. 05 正常帧区不再出现“高光帧可用”。
4. 无可用高光帧时仍显示真实不可用状态。
5. 报告测试、Python 编译、JavaScript 语法检查与真实报告重渲染通过。
