# 云图第 02 章 Top N 与营销卖点联动设计

## 目标

让第 02 章每个范围内的 Top N 控件同时驱动人群图表和营销卖点汇总。用户调整 Top N 后，两个图表都只基于该范围排名前 N 条素材计算。

## 范围

- 保持现有全量 TOP1000 和各品牌 scope 的独立素材池与默认最大值。
- 保持当前人群图表、营销一级类别柱状图和类别下钻的可访问性。
- 不改动事实包、AI 结论、RPA 或榜单口径。

## 数据与交互

每个 `audience-dashboard` 已嵌入按排名排序的 `topMaterials`。渲染时将其同时提供给人群和营销卖点客户端逻辑。

`renderTopN(n)` 将数值限制在 1 到当前 scope 的素材总数，随后：

1. 使用前 N 条素材刷新年龄、性别和八大人群图表。
2. 从同一批素材的 `material_tags` 重新归类并计数，刷新营销卖点一级类别柱状图和总计说明。
3. 如当前展示营销类别下钻，回到刷新后的营销总览，避免旧范围下的标签明细继续显示。

切换 scope 不共享 Top N 状态；每个 scope 初始展示自身的全部可用素材。

## 验证

- 单元测试证明展示投影保留素材记录，并证明渲染出的脚本在 Top N 更新路径调用营销卖点重算和总览刷新。
- 使用真实严格批次重渲染，检查 4 个 scope 均有控件，且 HTML 包含联动逻辑。
- 运行全量单元测试、Python 编译检查和 `git diff --check`。
