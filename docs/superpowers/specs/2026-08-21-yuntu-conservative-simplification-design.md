# 云图技能保守简化设计

## 目标

在不改变云图行业内容榜单分析行为的前提下，减少技能入口的重复说明，并删除经全仓引用审计确认的私有死代码。

## 范围

- 将 `SKILL.md` 收敛为运行入口：输入和周期、凭据边界、采集到报告的命令顺序、恢复语义、成功交付门禁和产物定位。
- 将章节级 schema、字段穷举和渲染实现细节保留在现有脚本验证器与提示词模板中，不再在入口重复维护。
- 删除仅在定义处出现、没有调用点的私有函数；每个删除项必须先有失败的存在性契约测试。

## 不变项

- CLI 参数、固定 RPA function code、超时策略、详情波次并发（2）、高光并发（3）及波次等待顺序。
- `batch-manifest.json`、`run-summary.json`、规范化 records、事实包、分析 provenance 和报告的 schema。
- 已落盘详情恢复、分组补位、`rejectedMaterials`、`unresolvedMaterials` 与两类显式重试语义。
- 分析必须按 `prepare-analysis -> 模型分析 JSON -> attest-analysis -> render-report` 执行；不得程序化兜底生成业务结论。
- 认证值只存在于运行环境，绝不写入文档、测试、命令记录或产物。

## 设计

`SKILL.md` 保留单一线性主路径及异常分支：先发现账号和自检，使用新输出目录采集，以 `status` 观察异步落盘，成功后准备事实包、登记模型分析来源并渲染报告。它只引用脚本作为 CLI/schema 权威，不重复描述具体 JSON 字段、五章内部展示规则或高光提取算法。

脚本清理只接受静态引用审计与测试共同证明的死代码。本轮已识别的候选是 `scripts/rpa_connector.py` 的 `_safe_error_summary`：它自引入以来无任何调用点，且当前错误路径直接使用受现有凭据安全测试覆盖的异常传播。不会为消除少量重复而抽取调度、状态或重试辅助层。

## 验证

- 对每个删除项先添加会因符号仍存在而失败的契约测试，再执行最小删除。
- 更新技能契约测试，覆盖入口仍包含周期映射、认证边界、恢复/重试、模型来源回执和成功交付门禁。
- 执行 `python -m pytest -q` 与 `git diff --check`。
- 在可用运行时认证环境中，使用新的独立输出目录执行一次真实 RPA 回归，并以 `status: success` 作为运行层结论。
