# 第四章高光画面品牌分层与资产导出设计

## 目标

在不改变第一、二章既有契约、也不把第五章逐帧观察并入第四章的前提下，提升第四章视觉分类的可靠性，增加“品牌 → 视觉类型”的两级筛选，并支持将报告中的可用高光帧导出为 Excel。

## 设计

### 分类与事实边界

- `highlight-input.json` 继续是第四章唯一事实入口。
- 代码根据素材标题和用户输入品牌做确定性品牌归属；模型不负责猜品牌。
- 模型只对 `available=true` 的本地 JPEG 判断主视觉类型：`portrait`、`product`、`other`。
- 每张可用帧必须且只能属于一个品牌和一个视觉类型。
- `common_patterns` 与 `derivative_directions` 统一为 `title`、`body`、`frame_refs` 对象结构，分析思路保持不变；旧式字符串共性洞察仅用于兼容历史结果。

### Presentation 与 HTML

第四章 Presentation 改为品牌一级、视觉类型二级：

```text
chapter04
└── brands[]
    ├── brand
    └── categories[]
        ├── portrait
        ├── product
        └── other
```

品牌顺序按用户输入顺序。HTML 先展示品牌 Tab，再展示该品牌下的视觉类型 Tab；每个类型面板仍按“共性洞察 → 裂变方向 → 高光帧卡片 → 分页”展示。

### Excel 导出

第四章增加“导出高光帧资产”按钮。报告生成阶段使用工作区提供的 `@oai/artifact-tool` 预生成一个 `.xlsx`，HTML 按钮下载该静态文件；工作簿开启品牌和视觉类型筛选，用户可在 Excel 中继续筛选。

每行一张高光帧，字段为：品牌、视觉类型、素材排名、素材 ID、素材标题、画面类型（封面画面/点击 TopN 波峰画面）、高光帧图片、秒数、点击峰值排名、点击指数。高光帧图片直接嵌入 Excel，不再将 `frame_ref` 或本地图片路径作为用户可见列。

导出不包含失败帧，不上传图片，不改变报告静态部署方式。

## 验收标准

1. 旧三类分类仍可渲染，新增 `other` 时可展示。
2. 品牌 Tab 位于视觉类型 Tab 之上，品牌和类型切换互不串状态。
3. 所有可用帧按标题品牌确定性归属，并且唯一覆盖。
4. 共性洞察、裂变方向按统一对象结构展示，仍保持“共性洞察 → 裂变方向”的顺序。
5. Excel 支持品牌/类型筛选，且每行包含报告卡片所需的全部关键信息。
6. 第一、二章与第五章自动化测试保持通过。
