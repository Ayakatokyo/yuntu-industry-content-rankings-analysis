# 第二部分图表提示与横向滚动设计方案

## 背景

最新营销卖点分类按下划线前缀拆分一级标签，一级分类数量从原先较少的类别扩展到 16 类。当前营销卖点柱状图使用 Grid `auto-fit`，在桌面宽度不足时自动换行，造成图表高度增加、阅读顺序不连续。

## 目标

1. 八大人群分布的交互提示与标题同一行展示，位于标题右上角。
2. 营销卖点汇总的交互提示更换为指定文案，与标题同一行展示，位于标题右上角。
3. 在营销卖点标题下增加一级/二级标签分类规则说明。
4. 营销卖点一级分类柱状图始终单行排列，超出可视区域时提供横向滚动。

## 设计

### 标题行

报告渲染层为八大人群和营销卖点分别生成 `section-title-row`（现有标题元素可在原地升级），标题左对齐，提示文本右对齐。提示文本使用加粗、较正文更大的字号；在窄屏通过 `flex-wrap: wrap` 或等效规则自然换行，不遮挡标题。

八大人群提示文案保持为：`点击柱状图查看对应人群 TOP3 素材`。

营销卖点提示文案改为：`点击一级标签柱状图可查看二级标签分布`。

### 分类规则说明

营销卖点标题下紧接说明段，使用普通说明字号和弱化颜色：

> 营销卖点标签分类规则以完整营销卖点中括号里的内容为一级标签。由于 RPA 提取的营销卖点数据以下划线区分层级，而下划线不会透出，因此此处以云图官方界面显示作为解释。

说明段不参与点击交互，不改变事实包字段。

### 单行横向滚动

营销卖点柱状图容器改为 `display:flex; flex-wrap:nowrap; overflow-x:auto`，每个一级分类柱使用固定的最小/基础宽度（桌面 86px，移动端 68px），通过 `flex: 0 0 <width>` 防止压缩和换行。保留原有柱高、比例、悬停态、键盘焦点态及点击下钻逻辑。滚动容器增加 `tabindex="0"`、`role="region"` 和中文 `aria-label`，确保键盘与读屏用户可理解横向内容。

八大人群柱状图不改变数据布局，仅同步标题提示样式。

## 兼容与边界

- 分类为空时仍显示现有空数据提示。
- 一级分类超过容器宽度时只增加滚动，不改变报告整体宽度。
- 窄屏标题行允许换行，横向滚动区域保持可用。
- 不修改 RPA、事实包或营销标签解析规则。

## 验收标准

- 八大人群提示在标题右侧、加粗且字号大于普通提示。
- 营销卖点提示文案完全匹配指定文本并位于标题右侧。
- 规则说明出现在营销卖点标题正下方且文本完整。
- 16 个一级分类在同一水平行，容器存在横向滚动能力，无第二行分类柱。
- 现有图表点击下钻、键盘焦点和 71 项报告测试不回归。
