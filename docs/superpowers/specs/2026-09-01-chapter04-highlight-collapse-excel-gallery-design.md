# 第四部分高光帧折叠与 Excel 图片墙设计方案

## 目标

优化第四部分“高光画面洞察”的阅读和导出体验：高光帧卡片可展开/收起；Excel 图片完整可见；新增只展示高光帧的分类图片墙。

## 交互设计

每个高光帧分类面板（人像画面、产品画面、其他画面）保持现有分类 Tab、共性结论和裂变方向内容始终可见。面板顺序为：

`共性结论与裂变方向 → 展开/收起高光画面汇总按钮 → 高光帧卡片与分页`

按钮复用人群/脚本汇总的折叠控件样式，默认展开，使用 `aria-expanded` 和 `aria-controls` 关联卡片面板。收起时仅隐藏高光帧卡片网格及分页，不隐藏文字洞察；按钮文案在“收起高光画面汇总”和“展开高光画面汇总”间切换。

## Excel 设计

### 高光帧资产 Sheet

使用 `openpyxl + Pillow` 统一生成工作簿。高光帧图片按原始宽高比等比缩放并限制在图片列可视范围内，同步设置图片列宽、数据行高和冻结表头，确保图片完整、不变形、不被相邻行遮挡。现有业务字段、筛选和视觉类型字段保留。

### 高光帧图片墙 Sheet

新增只负责图片展示的 `高光帧图片墙` Sheet。顶部提供“全量 / 人像画面 / 产品画面 / 其他画面”四个内部定位入口；下方按范围分区展示该范围内全部高光帧图片。该 Sheet 不放素材排名、点击指数等业务指标，仅保留图片及最小识别信息（素材标题、画面类型）。采用无宏的工作簿内部链接，兼容 Excel/WPS；各图片按统一画廊卡片尺寸等比缩放并设置行高列宽。

## 边界与验收

- 没有可用高光帧时维持现有空状态。
- 三类面板的文字洞察始终可见，折叠只作用于卡片和分页。
- 图片墙四个范围均覆盖对应的全部图片，图片数量与事实包一致。
- 现有 HTML 交互、品牌 Tab、图片预览和分页行为不回归。
