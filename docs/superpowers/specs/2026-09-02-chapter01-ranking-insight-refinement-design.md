# 第一部分素材榜单洞察展示细化设计方案

## 目标

在既有第一部分事实包、提示词和报告渲染优化基础上做最小调整：强化全行业对比语义，重命名表现洞察和对比面板，优化曝光口径与数值格式，并调整对比面板位置。现有爆款素材事实卡片继续保留。

## 事实包调整

三批榜单素材列表继续沿用现有实现：当前默认筛选周期、默认筛选条件的环比周期、同周期全行业数据。素材列表行中的曝光字段改为只保留榜单返回的区间展示值（例如 `20万-30万`），移除素材级曝光确定值及其等价的数值副本；CTR、CVR、3 秒完播继续保留。

为支持三组筛选条件的比较，既有聚合比较事实继续保留其当前统计口径。聚合事实中的曝光总量和变化值不再被当作单条素材曝光真值，报告渲染时统一转换为中文单位和带符号的可读文本（如“减少 115.6 万次”），禁止出现 `-1.156e+06` 等科学计数法。若某个曝光区间无法解析，输出不可用状态，不推导确定值。

## 提示词调整

保留现有 `dataSummary` 与 `hotMaterialInsight` 双字段结构。仅强化 `dataSummary` 的表达顺序与措辞约束：

1. 先明确默认筛选条件当前表现及四项指标；
2. 使用“环比看”明确说明与环比周期的变化；
3. 使用“与全行业大盘对比看”明确说明与同周期全行业数据的差异；
4. 再形成业务判断、可能机制、策略和验证建议。

模型不得只用“较行业大盘”“高于大盘”等模糊短语代替完整的行业对比句式，也不得重新计算事实包中的曝光值。`hotMaterialInsight` 维持现有爆款整体洞察语义，不逐条复述素材卡片。

## 前端报告调整

每个 Tab 的章节一结构调整为：

```text
素材表现洞察
├─ dataSummary：当前表现、环比、全行业对比 AI 段落

环比与全行业对比
└─ 可展开/收起的三组筛选条件数据指标与变化

爆款素材洞察
├─ hotMaterialInsight：爆款 AI 段落
└─ 现有爆款素材事实卡片
```

具体规则：

- “素材表现与行业对比”标题改为“素材表现洞察”。
- 对比事实标题改为“环比与全行业对比”。
- 按钮文案改为“收起环比与全行业对比数据”和“展开环比与全行业对比数据”。
- 对比面板移动到“素材表现洞察”和“爆款素材洞察”之间。
- 对比面板展开后先展示当前默认筛选条件指标，再展示环比周期对应变化，最后展示同周期全行业对应变化。
- 对比面板复用现有爆款素材汇总面板的折叠控件、无障碍属性、默认状态和键盘交互。
- 曝光及曝光变化统一使用中文单位格式化；其他指标沿用既有百分比格式。
- 爆款素材事实卡片的位置、字段、数量、排序和交互保持不变。

## 验收标准

- 生成的素材列表不含素材级曝光确定值，只含曝光区间展示值。
- AI 表现洞察同时明确出现环比与全行业对比语义。
- 页面标题、按钮文案和面板顺序符合本方案。
- 对比面板完整呈现当前、环比、同周期全行业三组指标及变化。
- 页面中不出现科学计数法曝光值。
- 现有爆款素材卡片和其交互无回归。
