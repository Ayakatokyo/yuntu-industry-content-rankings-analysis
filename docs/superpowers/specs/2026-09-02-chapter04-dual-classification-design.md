# 第四部分高光帧双分类标准设计方案

## 目标

在保留现有“人像 / 产品 / 其他”高光帧面板的基础上，新增“本批次标准”切换能力。系统先对每张高光帧进行图片理解，再综合同一批次的理解结果生成分类规则并重新归类；两套分类结果并存，仅在指定品牌 Tab 的高光帧卡片区域切换展示。

## 适用范围

切换控件只出现在以下第四部分品牌 Tab 的高光帧卡片区域：

- 所有指定品牌
- Joyoung soymilk
- 九阳豆浆
- 燕之屋
- WONDERLAB
- 万益蓝

标准分类默认选中。切换不影响第一、二、五部分，也不改变第四部分其他非卡片内容。

## 数据与分析链路

阶段一对每张可用高光帧生成图片理解结果，至少描述主体、视觉焦点、占比、人物与产品关系、动作、构图和信息表达，不在此阶段强制归入固定类别。

阶段二读取同一批次全部高光帧理解结果，生成该批次的分类名称、分类规则、分类顺序和每类帧引用，再按该规则完成全量归类。事实包同时保留：

- `standardClassification`：现有人像、产品、其他及其帧引用；
- `batchClassification`：本批次分类规则、分类说明、分类组和帧引用。

两套结果必须引用同一批已成功采集的高光帧，不重复生成图片，不修改图片事实。分类失败或证据不足时，保留标准分类并将本批次标准标记为不可用及原因。

## 前端交互

在指定品牌 Tab 的高光帧卡片区域增加可访问的标准切换控件：

```text
分类标准：[标准分类] [本批次标准]
```

选择“标准分类”时，继续展示人像、产品、其他三个既有面板；选择“本批次标准”时，读取 `batchClassification` 的动态分类名称和规则，重新渲染分类 Tab/分组及对应全部高光帧卡片。图片预览、分页、卡片字段和排序规则沿用现有实现。

控件默认选择标准分类；本批次分类不可用时，切换项置灰并展示不可用原因。切换只控制品牌 Tab 内的高光帧卡片内容，不影响其他洞察文字和章节结构。

## 验收标准

- 每张成功高光帧都有可追溯的图片理解结果或明确失败原因。
- 本批次分类规则由整批理解结果生成，同一批次内保持一致。
- 标准分类结果与现有报告一致，默认视图不回归。
- 指定品牌 Tab 可独立切换标准分类和本批次标准；非指定范围不出现该控件。
- 两种模式下的高光帧数量与事实源一致，不能重复或丢失。
- 无可用本批次分类时安全降级，不编造分类。
