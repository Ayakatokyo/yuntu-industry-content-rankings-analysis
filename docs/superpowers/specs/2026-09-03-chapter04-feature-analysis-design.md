# 第四部分分类与高光帧特征分析设计方案

## 目标

调整第四部分的分类信息架构，并新增基于高光帧图片可观察信息的特征分布分析：

1. 删除“本批次标准”模式中的共性洞察和裂变方向，不再要求模型生成或报告渲染 3+3 洞察；
2. 删除页面中的“分类标准：”说明文字，但保留双模式切换；
3. 将标准分类 Tab 改为“产品”“人像”“其他”，移除固定分类规则说明；
4. 将本批次模式改名为“本批次视觉主题”，明确它是基于本批次图片理解生成的自定义主题；
5. 新增“高光帧特征分析”Tab，以竖向柱状图展示视觉特征、画面结构、拍摄视角、场所/背景、字幕表现等类别的占比。

## 范围与不可做事项

图片理解只对静态画面中可观察的事实负责。允许识别主体、构图、颜色/光线、人物与产品关系、静态拍摄视角、场所/背景、字幕存在与视觉样式，以及分屏、画中画、录屏、直播间界面等可见画面结构。

单张图片不能可靠证明视频的剪辑节奏、镜头切换频率、转场类型、前后镜头因果关系。因此“剪辑形式”统一落为“画面结构”，不输出动态剪辑结论；低清、遮挡或无法辨识的字幕和场所进入“无法判断”，不得强行猜测。

## 页面信息架构

第四部分在每个品牌范围内保持以下结构：

```text
品牌 Tab
  └─ 分类模式 Tab
       ├─ 产品
       ├─ 人像
       ├─ 其他
       ├─ 本批次视觉主题
       └─ 高光帧特征分析
```

“产品/人像/其他”页面只展示分类对应的高光帧卡片和分页，不展示“分类规则：”说明，也不展示共性洞察或裂变方向。

“本批次视觉主题”只展示 AI 自定义分类组、分布柱状图、高光帧卡片和分页；删除共性洞察、裂变方向及其标题。原有分类分布图保留，但标题改为“本批次视觉主题分布”。

“高光帧特征分析”展示一个维度选择器（全部、视觉特征、画面结构、拍摄视角、场所/背景、字幕表现）和一个竖向柱状图。横轴是带维度前缀的类别名，例如“场所：户外环境”；纵轴是类别占比（%）。Tooltip 和无障碍标签同时提供类别、占比、帧数、去重素材数。

## 数据契约

模型在现有逐帧 `frameUnderstanding` 基础上，为每个成功高光帧增加 `featureAnalysis`：

```json
{
  "frame_ref": "...",
  "dimensions": {
    "visual_feature": {"category": "人物近景", "confidence": "high"},
    "visual_structure": {"category": "单画面", "confidence": "high"},
    "camera_view": {"category": "正面平视", "confidence": "medium"},
    "scene_background": {"category": "户外环境", "confidence": "high"},
    "subtitle": {"category": "黄色底红色字", "confidence": "medium"}
  }
}
```

每个维度每帧只能有一个类别；无法判断时使用 `无法判断` 并记录原因。Presentation 从真实成功 `frame_refs` 确定性生成 `featureAnalysis`，不采信模型生成的 count/share。

每个维度的统计字段为：

```json
{
  "dimension": "scene_background",
  "label": "场所/背景",
  "totalFrames": 12,
  "totalMaterials": 8,
  "buckets": [
    {
      "category": "outdoor",
      "label": "场所：户外环境",
      "frameCount": 5,
      "materialCount": 4,
      "share": 0.5
    }
  ]
}
```

`frameCount` 是类别中高光帧数量；`materialCount` 是类别涉及的素材 ID 去重数量；`share` 使用去重素材数作为分子和同一分析范围内去重素材总数作为分母。素材 ID 只来自事实包，不使用标题。若一个素材同一维度出现多个类别，Presentation 按该素材在成功帧中的主类别归一，保证同一维度的素材占比合计 100%。

## 错误与兼容策略

- 没有成功高光帧时，特征 Tab 显示“暂无可用高光帧”，不生成空图表；
- 特征字段缺失或不完整时，保留分类页面并在特征 Tab 显示明确不可用原因；
- 历史分析 JSON 没有 `featureAnalysis` 时不报错，旧报告不改写，新报告只显示不可用提示；
- 历史 `common_patterns`、`derivative_directions` 可读取但新渲染忽略，避免旧数据阻塞渲染；
- 既有 Excel 导出继续保留三 Sheet 和双分类字段，不把特征分析图片或图表写入 Excel，除非后续另行提出需求。

## 验收标准

1. HTML/Markdown 不出现“分类标准：”，标准模式 Tab 文案精确为“产品”“人像”“其他”；
2. 本批次模式文案精确为“本批次视觉主题”，不出现共性洞察、裂变方向及其内容；
3. 每个品牌范围都有“高光帧特征分析”Tab；图表横轴显示维度类别，纵轴为百分比，Tooltip 含帧数和去重素材数；
4. 同一维度素材占比总和约等于 100%，桶的帧数/素材数均由真实引用确定性计算；
5. 图片不可判断的维度明确进入“无法判断”，不能编造动态剪辑结论；
6. 双分类切换、分页、图片预览、按需 Excel 导出、第一/二/五部分无回归。
